Connect to a live PostGIS

      

        
This explorer ships a simplified snapshot of the teaching
          database so it runs on a static host with zero setup. A browser cannot open a raw
          PostgreSQL connection directly, so to query a live database you point a small
          read-only proxy at it and query through that.

        
The repo's interactive/export/export.sh shows the exact PostGIS
          SQL used to build these layers — run it against your own DB_URL to refresh
          the snapshot, or adapt it to add tables.

        
set -a && source .env && set +a   # provides DB_URL
cd interactive/export && ./export.sh
